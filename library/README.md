# Pattern library

Tracks built by `track.create` and exported with `pattern.export`.
Load one back with `pattern.import`, into any slot:

```
tr8s call pattern.import '{"slot": "8-12", "pattern": <the json>}'
```

Each carries its style, key and seed, so it can be rebuilt or varied
rather than only replayed. Melodies are stored as note names against
the tone's measured root; they need `MOTION [ON]` and Coarse Tune on
that instrument's CTRL knob to be audible.

## What each one is

**HYPNO** — 5- and 7-step cycles against the four. F# phrygian, 132 BPM.

**PEAKTIME** — driving peak-time techno. C minor, 138 BPM.

**ACIDTRAX** — 303 line with accents over 16th hats. A minor, 138 BPM.

**DUBTECH** — soft kick, offbeat stabs, space. D minor, 118 BPM.

**HARDTEK** — rolling kick, no room left. G phrygian, 146 BPM.

**MINIMAL** — sparse, an arpeggio turning under it. F# phrygian, 129 BPM.

**BROKEN** — the kick syncopates. E minor, 133 BPM.

**SLOWJAM** — soft and behind the beat. A minor, 110 BPM.

**ROLLERS** — two-step at 174. F minor, 174 BPM.
